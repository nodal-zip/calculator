# Calculator

A clean, responsive web calculator built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations (`+`, `-`, `×`, `÷`)
- Percentage (`%`), sign toggle (`±`), clear (`AC`), and backspace (`⌫`)
- Chained calculations and decimal precision handling
- Division-by-zero protection
- Full keyboard support (`0-9`, `.`, `+`, `-`, `*`, `/`, `Enter`/`=`, `Backspace`, `Escape`)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/nodal-zip/calculator.git
   ```
2. Open `index.html` in your browser.
